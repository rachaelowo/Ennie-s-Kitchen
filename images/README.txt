HOW PHOTOS WORK ON THIS SITE
=============================

Every dish on the Home and Menu pages tries to load a photo from this
"images" folder automatically. You don't need to touch any code — just
drop a .jpg file into this folder using the EXACT filename listed below
for that dish, and it will appear on the site immediately (refresh the
page to see it).

If a file isn't there yet, the site shows a soft color placeholder
instead, so nothing looks broken while you add photos over time.

Requirements for each photo:
- Format: .jpg
- Filename: exactly as listed below (lowercase, hyphens, no spaces)
- Recommended size: at least 800x600px, roughly a 4:3 or square photo
  works best (it will be cropped to fit automatically)
